# Strongman Speaker

Instalowalna PWA do przygotowywania reklam sponsorów i mecenasów podczas zawodów Strongman.

## Publikacja
GitHub Pages: https://jarekdymek.github.io/StrongNew/speaker/

## Funkcje
- lokalna synteza polskiego głosu Piper bez klucza API,
- głosy: Darkman, MC Speech, MLS 6892,
- proceduralne podkłady Arena Pulse, Sponsor Glow i Victory Bed,
- miks głosu z muzyką, eksport MP3/WAV,
- biblioteka reklam offline w IndexedDB,
- osobny Tryb Zawodów,
- instalacja jako PWA na Androidzie.

## Pierwsze uruchomienie
Przy pierwszym użyciu uruchom aplikację z internetem i wybierz „Pobierz wszystkie”, aby zapisać modele głosowe lokalnie. Potem zapisane modele i reklamy mogą działać offline.
